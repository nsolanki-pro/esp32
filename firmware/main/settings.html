Wi-Fi network

To switch networks, use the setup page. The new network is tested before it replaces the current one.

Admin password

Protects firmware updates, Wi-Fi changes and reset.

Factory reset

Forgets the Wi-Fi network and the admin password, then reboots into setup mode: the device opens the network ESP32-Setup-XXXX (WPA3, password esp32setupXXXX, same XXXX) until it is configured again. Firmware is kept.
