Network

Wi-Fi network: change network (the new one is tested before it replaces the current one).

Applying reconnects Wi-Fi and checks the gateway. If that fails within 30 s, the previous settings come back by themselves. Lower TX power saves energy when the router is close. Auto starts at full power, then lowers it to what the signal strength says the router needs, plus a margin; it goes back to full power by itself if the gateway stops answering.

Maintenance

Factory reset forgets the Wi-Fi network, the admin password and all settings on this page, then reboots into setup mode: the device opens ESP32-Setup-XXXX (WPA3, password esp32setupXXXX, same XXXX). Firmware is kept. Holding BOOT for 20 s does the same.
